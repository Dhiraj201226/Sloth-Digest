# Sloth Digest — Demo GIF & Video Walkthrough Script

This script outlines the frame-by-frame narrative for recording the 30-to-45-second product demo GIF or screencast for the Dev.to submission and GitHub repository banner.

---

## Technical Recording Setup
- **Resolution**: 1920 × 1080 (1080p, 60fps) or 1280 × 720 (720p).
- **Tool**: OBS Studio, Kap, or CleanShot X.
- **Theme**: Light Mode (`#FDFBF7` canvas, warm calm linen aesthetic).
- **Target Duration**: 35 seconds.

---
